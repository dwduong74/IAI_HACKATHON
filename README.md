# Dự án IAI HACKATHON 2025

Kho lưu trữ này chứa bài nộp cho cuộc thi IAI HACKATHON 2025.

## Mô tả dự án

(Vui lòng cung cấp mô tả chi tiết về dự án của bạn, vấn đề nó giải quyết và các công nghệ được sử dụng.)

## Nội dung

- `IAI_HACKATHON_2025/eg.cpp`: Tệp mã nguồn chính của dự án.

## Cách biên dịch và chạy

Bạn có thể biên dịch tệp mã nguồn C++ bằng một trình biên dịch C++ tiêu chuẩn như `g++`:

```bash
cd IAI_HACKATHON_2025/
g++ -o ten_tep_thuc_thi eg.cpp
./ten_tep_thuc_thi
```
*Lưu ý: Thay thế `ten_tep_thuc_thi` bằng tên bạn muốn đặt cho tệp thực thi.*

## Nộp bài

Kho lưu trữ này được sử dụng để công bố mã nguồn và nộp bài thi.
